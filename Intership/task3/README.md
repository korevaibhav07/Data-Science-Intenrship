TRUERP Website Web Scraping

This task focuses on extracting structured information from the given TRUERP website.

# Work Done
- Tried HTTP-based scraping and observed 406 (Not Acceptable) due to bot protection.
- Implemented browser-based web scraping using Playwright.
- Extracted website headings (H1, H2, H3).
- Stored the extracted data in CSV format for analysis.

# Files
- scrape_truerp.py – Browser-based scraping script
- task3.ipynb – Jupyter notebook with the complete workflow
- truerp_headings.csv – Extracted dataset
