## Task 4 – Text Preprocessing & Keyword Analysis (TRUERP)

In this task, I worked on the data extracted from the TRUERP website in the previous task.

### Work Done
- Loaded the scraped website heading dataset.
- Performed text preprocessing (lowercasing and removal of special characters).
- Conducted keyword frequency analysis to identify important business-related terms.
- Stored the keyword analysis results in CSV format for further analysis.

### Files
- task4.ipynb – Jupyter notebook containing preprocessing and analysis steps
- outputs/keyword_frequency.csv – CSV file with extracted keywords and their frequencies
